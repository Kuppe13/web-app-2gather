2GATHER

2GATHER er en webapplikation udviklet som eksamensprojekt på 2. semester på Multimediedesignuddannelsen ved Erhvervsakademi Aarhus.

Formålet med løsningen er at gøre det lettere for brugere at finde lokale aktiviteter, deltage i events og skabe nye sociale relationer gennem fælles interesser og oplevelser.

Funktioner:
Opret events
Vis liste over events
Se detaljer for et event
Rediger eksisterende events
Slet events
Gem favoritter
Profilside
Lottie-animationer ved oprettelse og sletning af events
Teknologier
React
React Router
Supabase REST API
CSS
Lottie React
Installation
Klon repository:
git clone [repository-url]
Installer dependencies:
npm install
Start udviklingsserveren:
npm run dev
Miljøvariabler

Projektet benytter en .env fil med følgende variabler:

VITE_SUPABASE_URL=your_url
VITE_SUPABASE_APIKEY=your_api_key
